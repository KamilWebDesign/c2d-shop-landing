# Chat2Desk для интернет-магазинов — блоки для передачи в разработку

Собрано: 20261013-1910. Проверка пройдена на ширинах 360, 390, 768, 1024, 1280, 1440, 1920 px.

## Шаг 0 — один раз для всего сайта: шрифт Nunito Sans

Блоки сделаны в фирменном стиле 2026: текст набран **Nunito Sans**. На сайте его пока нет. Подключить нужно один раз для всего сайта; позже на него перейдут и шапка, футер и остальные блоки. Если это уже сделано, шаг пропустить.

1. Файлы `tpl/fonts/nunito-sans-*.woff2` и `tpl/css/fonts-2026.css` приедут на сайт вместе с папкой `tpl/` (шаг 1 ниже). Они одинаковые во всех архивах, перезапись безопасна.
2. В **общий шаблон** `<head>` (для всех страниц) добавить одну строку, до CSS страниц:
   `<link rel="stylesheet" href="/tpl/css/fonts-2026.css">`
3. Проверка: открыть страницу с блоками → DevTools → Console → `[...document.fonts].some(f => f.family.includes('Nunito Sans') && f.status === 'loaded')` должно вернуть `true`; во вкладке Network загружается `nunito-sans-cyrillic-wght-normal.woff2` со статусом 200.

Шрифт вариативный: все начертания (200–1000) в одном файле, два файла на кириллицу и латиницу, вместе ~47 КБ. Лицензия SIL OFL 1.1. Если шаг 0 не сделан, блоки не сломаются: текст покажется шрифтом OpenSans сайта.

## Как встроить

1. Скопировать папку `tpl/` в корень сайта (пути совпадают с `/tpl/...`).
2. В `<head>` страницы подключить `<link rel="stylesheet" href="/tpl/css/internet-magaziny-v2.css">` (так же, как `about.css` на «О нас»).
3. Содержимое `blocks.html` вставить внутрь `<div class="wrapper__content">`.
4. Перед `</body>` подключить `<script src="/tpl/js/internet-magaziny-v2.js"></script>` (чистый JS, без зависимостей).
5. **Бокового меню на странице нет.** `<aside class="aside">` не выводить, `.wrapper__content` — на всю ширину `.wrapper`: CSS сайта с 1440px сужает её под меню (`width: calc(100% - 232px)`, с 1688px `calc(100% - 414px)`), на этой странице нужно `width: 100%`. Так выглядит `preview.html`.
6. В `blocks.html` есть пометки «СТАНДАРТНЫЙ БЛОК САЙТА» — на их место вставить готовые блоки сайта без изменений: Форма заявки «Остались вопросы?» — `callback`, id="feedback".

## Важно знать

- Все классы начинаются с `c2l-` и не пересекаются с классами сайта. Стили блоков не выходят за блоки; от CSS сайта блоки не зависят (кроме шрифтов).
- Адаптив сделан на container queries: блок подстраивается под ширину контентной зоны, а не экрана (у сайта `zoom: 80%` на 1024–1920px, зона от 320 до 1624px).
- Блоки набраны только Nunito Sans — он приходит из `fonts-2026.css` (шаг 0). Внешних подключений (CDN) нет.
- Цвета блоков — фирменный стиль 2026 (синий #1E63B8). Шапка и футер сайта пока в старом стиле — это ожидаемо, их не трогать.
- В блоках нет атрибутов, которые перехватывают скрипты сайта (`data-step`, `data-submit`, `data-da`, `js-*` и т.п.).
